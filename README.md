# Currículo Online - Murilo Rodrigues

Currículo online interativo desenvolvido com HTML, CSS e JavaScript.

## 🚀 Funcionalidades

- Design responsivo para todos os dispositivos
- Modo claro e escuro
- Animações de fundo com partículas
- Integração com GitHub README
- Interface moderna e minimalista

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome Icons

## 📦 Como usar

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
3. Ou acesse a versão online no GitHub Pages
